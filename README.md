This project is a submission for the NASA Sapce Apps 2026 Hackathon. We are competing at the local level in KC with the challenge SPHEREx and Planet X. This website is designed to be a user-centric platform where they can provide astronomical coordinates (in Right Ascention and declination) and pull up photos from NASA's SPHEREx mission. The user can see all the images of different wavelengths and see the photos over time. The user can also overlay two photos to more clearly see the differences between them. This website was coded with minimal AI, used only to help fix minor bugs.
